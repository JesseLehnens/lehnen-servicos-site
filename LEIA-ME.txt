Arquivos:

ANTES DE PUBLICAR:
1. Troque https://SEU-DOMINIO.com.br/ no canonical pelo endereço final do site.
2. Envie o logo e fotos reais para personalizar os espaços indicados no site.
3. Revise as cidades efetivamente atendidas e os serviços oferecidos.
4. Não acrescente endereço residencial público se você atende na casa do cliente.

PUBLICAÇÃO GRATUITA — GITHUB PAGES:
1. Crie/acesse uma conta em https://github.com/
2. Crie um repositório público chamado lehnen-servicos-site.
3. Faça upload do arquivo index.html para a raiz do repositório.
4. Abra Settings > Pages.
5. Em Build and deployment, selecione Deploy from a branch; branch main e folder /(root); salve.
6. Aguarde a publicação. O endereço será semelhante a https://SEU-USUARIO.github.io/lehnen-servicos-site/
7. Substitua o canonical dentro do index.html pelo endereço final e envie o arquivo atualizado.
